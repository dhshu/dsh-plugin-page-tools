# 插件页搜索与分页

Host 半边（`lib/index.js`）不提供任何能力，浏览器半边（`lib/client.js`）只改变呈现，不改动宿主行为。

插件页保持官方版式。本插件在「已安装插件」分组（`data-plugin-group="bundles"`）的标题正下方放一个搜索框，并在卡片之后放一行靠右排列的内容：「第 1–10 条，共 25 条」、「每页 N 条」、页码，整体贴着行的右端。

- **搜索**匹配卡片的标题、简介和包名，大小写不敏感、空白折叠、按空格切词，要求每个词都出现；匹配数量（`9/25`）显示在搜索框右侧。
- **每页条数**默认 10 条，可改成 1–100 之间的任意整数，回车或失焦生效并记在本机（`localStorage` 的 `dsh-plugin-page-tools.page-size`）。改条数时保持当前屏幕上第一张卡的位置，不跳回第一页。
- **分页器**在这一行的最右边：首页、上一页、当前页附近以及首尾的页码、下一页、末页。只有一页时不显示页码按钮，只留条数和区间；查询无结果时隐藏卡片列表，改为显示「没有匹配「…」的插件。」。
- 官方页面每次重新渲染卡片都会重新应用一次视图，所以启用插件、刷新列表、切换标签都不会清掉搜索词和页码。

## 配置

无。本 bundle 不提供服务、工具或配置项。

## 说明

- 自有类名前缀 `dship-`，自有 DOM，只用主题变量（`--dsw-alias-*`、`--dsw-radius-*`、`--dsw-focus-ring-*`）。
- 文案通过 `ctx.locale` 注册 `zh` 与 `en`；插件展示信息在 `locale/zh.json`、`locale/en.json`。
